## 설치와 실행

1. `.exe` 파일을 받아 더블클릭하면 바로 실행됩니다. 따로 설치할 것이 없습니다. (Windows 10 / 11, 64비트)
2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
3. 체험판으로 바로 써 볼 수 있습니다. 구매 후 사이트의 **내 정보**에서 받은 라이선스 키로 정품 인증하세요.
